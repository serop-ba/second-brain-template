# Inbox

Dump zone. Anything, any format, no structure required — a link, half a
sentence, a screenshot path, a number you noticed. Capture friction is what
kills systems like this, so never stop to decide where something goes.

Emptied to zero during the weekly loop: I file each item into
[notes/](notes/), [goals.md](goals.md), [decisions.md](decisions.md), or
[raw/](raw/), then delete it from here.
